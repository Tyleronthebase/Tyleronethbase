把模糊需求做成可交付的 AI 产品、边缘全栈系统与真正有人用的工具。

## What I am building around

- **Agentic AI** — orchestration, tool use, model context, streaming, multimodal input, and human-in-the-loop workflows.
- **Edge-native full stack** — globally distributed apps built around Workers, D1, R2, KV, Queues, Workflows, and Durable Objects.
- **Product engineering** — owning the path from interaction design and frontend architecture to APIs, data, deployment, and observability.
- **Platform delivery** — containerized services, Kubernetes overlays, Argo CD GitOps, and automated GitHub/GitLab pipelines.
