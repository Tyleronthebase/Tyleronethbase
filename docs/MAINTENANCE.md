# Keeping this profile up to date

The profile is the root `README.md` in `Tyleronthebase/Tyleronthebase`. GitHub renders it on [the account overview](https://github.com/Tyleronthebase).

## Edit content and design

- Edit `README.md` for the introduction, project descriptions, and links.
- Edit `scripts/generate-hero.mjs`, then run `node scripts/generate-hero.mjs` to rebuild both banners.
- Keep the two theme palettes consistent with `DESIGN.md` and the statistics generator.
- Commit both the source and generated SVGs. No web server or npm install is required.

## Refresh the charts

The **Refresh profile assets** workflow runs daily and can also be run manually from the repository's Actions tab. It generates public repository statistics and the contribution snake, then commits the SVGs to the default branch. It uses the repository's built-in `GITHUB_TOKEN`; no personal access token or additional secret is required.

To refresh only the repository statistics locally, run:

```sh
node scripts/update-stats.mjs
```

An existing `GH_TOKEN` or `GITHUB_TOKEN` can raise the API request allowance. Never place a token in this repository or in image URLs.

Repository counts exclude the profile repository. Language distribution uses GitHub's reported code bytes in public, non-fork, non-archived projects. It is a repository snapshot, not a skill rating. The fork remains clearly attributed in the project list. The snake uses the contribution calendar returned to the workflow token.

Images are stored in `assets/`, so a failed scheduled update leaves the last committed charts visible. If an update fails, inspect the workflow logs and rerun it. GitHub may delay scheduled jobs; the statistics image includes its UTC generation date. If branch rules block bot pushes, allow this workflow through the existing review process rather than disabling branch protection.
